2. Ket luan nhanh ve 3 yeu cau

Yeu cau 1: Luu ket qua chay
- DAT.
- Script ghi history_<model>.csv cho tung model:
  + history_classical.csv
  + history_hybrid.csv
  + history_full_quantum.csv
- Moi file history co cac cot:
  epoch, phase, train_loss, train_accuracy, validation_loss, validation_accuracy, lr_core, lr_readout, epoch_seconds.
- Script ghi summary.json de tom tat ket qua tot nhat theo validation loss.
- Script ghi config.json de luu cau hinh/lua chon command line da chay.

Yeu cau 2: Luu du trong so va tham so model
- DAT ve trong so model.
- Moi checkpoint *_best.pt co model_state_dict, epoch, row.
- Moi checkpoint *_last.pt co model_state_dict, optimizer_state_dict, scheduler_state_dict neu co, epoch, row, best, stale, rows, shuffle_rng.
- config.json luu cac tham so chay nhu seed, split-seed, batch size, learning rate, epoch, patience, model duoc chay, out-dir...
- Luu y: kien truc model nam trong source code models/ va cac hang so trong run_convergence.py. De tai lap day du, can giu lai ca source code + config.json + checkpoint .pt.

Yeu cau 3: Ve hinh so sanh
- DAT.
- Script tao 2 hinh:
  + convergence_all.png: so sanh cac model tren cung truc, gom loss va accuracy.
  + convergence_per_model.png: moi model mot khung rieng, danh dau validation loss nho nhat.
- Lenh --plot-only se ve lai tu cac file history_*.csv da co, khong train lai.

6. Y nghia cac file dau ra chinh

config.json
- Luu tham so command line va cau hinh train.

history_<model>.csv
- Luu ket qua theo tung epoch: train loss/accuracy, validation loss/accuracy, learning rate, thoi gian epoch.

summary.json
- Luu ket qua tong hop, gom best_val_loss, best_val_epoch, val_accuracy_at_best_loss, final_train_loss, final_val_loss.

*_best.pt
- Luu trong so model tot nhat theo tieu chi cua phase.
- Classical/hybrid va phase 3 full quantum chon theo validation loss nho nhat.
- Phase 1/2 full quantum chon theo validation accuracy cao nhat.

*_last.pt
- Luu trang thai moi nhat de resume, gom model, optimizer, scheduler neu co, lich su rows va RNG shuffle.

convergence_all.png
- Hinh so sanh train/validation loss va accuracy cua cac model tren cung do thi.

convergence_per_model.png
- Hinh loss rieng tung model, co danh dau validation loss nho nhat.

7. Ket luan cuoi

Theo code run_convergence.py, cac lenh trong README.md dap ung du 3 viec:
1. Co luu ket qua chay vao CSV/JSON.
2. Co luu trong so model va trang thai resume vao checkpoint .pt; config.json luu tham so chay.
3. Co ve hinh so sanh convergence_all.png va convergence_per_model.png.

Can cai du dependency, dac biet torchvision, truoc khi chay tren may hien tai.

8. Cap nhat code theo yeu cau moi

Da sua run_convergence.py de:
- In thu muc output va vi tri config.json ngay khi bat dau run.
- In thoi gian tung epoch nhu cu.
- In them tong thoi gian cua moi phase, vi du:
  [fq_phase3_reupload] finished 57 epoch(s) in 15h 20m 10s (55210.0s) reason=early_stop_patience
- In them tong thoi gian cua moi model, vi du:
  [full_quantum] total time 16h 05m 31s (57931.2s)
- In tong thoi gian toan bo run, vi du:
  [run] total time 16h 08m 02s (58082.4s)
- Ghi config.json chi tiet hon vao --out-dir, gom:
  command da chay, working directory, output directory, effective_args, data split, architecture, training_plan, resume, plotting, expected_outputs, environment Python/Torch/CUDA.
- Ghi run_time.json sau khi hoan tat, gom total_seconds, total_duration, completed_at.
- Ghi them phase_seconds va phase_duration vao tung file *_done.json.

Da kiem tra logic/cau truc bang:
python -m py_compile run_convergence.py

Ket qua: qua kiem tra cu phap, khong chay train.
